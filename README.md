# Define-hackathon-project
This is a repository for the Define hackathon organized 22-24 may 2025. The main object of the repository is to be able to approximate the wind speed and potentially the direction from visual information present in a video. Due to time constraints there is a lot to be improved in the code, but it is a functioning prototype.


The main idea is to use a depth model to approximate the distances in the video and optical flow for approximating the movement happening in the scene. This would then be used for creating a running average of the movement on all major axis.
